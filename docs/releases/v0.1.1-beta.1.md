# Loom 0.1.1 Beta 1

This preview adds a Windows x64 MSI and Windows compatibility work. It does not replace the Linux x86_64 beta; this release asset is Windows-only.

## What's new

- Build a Windows x64 installer and install a user-local TinyTeX/TexLab toolchain.
- Discover Windows LaTeX and native Codex/OpenCode executables.
- Preserve CRLF source files through editing, undo, and redo; improve Windows project saves and exports.
- Improve Windows Git status handling and launch the built-in sample with its first PDF build.

## Known limitations

- The app and MSI are unsigned. On the verification PC, Windows Application Control blocked the installed app from launching. Do not disable or bypass that policy; use a trusted signed build or ask the device administrator to approve this build.
- Windows Git desktop integration and authenticated live agent sign-in were not verified. This preview does not claim full Windows release verification.
- Linux remains available from the existing [0.1.0 Linux beta](https://github.com/monabji/Loom/releases/tag/v0.1.0-beta.1).
