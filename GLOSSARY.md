# Loom glossary

- **Project**: An ordinary folder containing a paper's source and assets.
- **Project library**: The list of known projects from which a user opens a workspace.
- **Workspace**: The open project's editor, PDF, references, and conversations.
- **Recovery**: Retained writing that a user can inspect after interruption or conflict.
- **Release candidate**: A packaged build awaiting all stable acceptance evidence.
- **Supported environment**: An operating system, architecture, and display session that passes the packaged release checks.
